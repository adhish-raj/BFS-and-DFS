
# File System Representation and Search Using BFS and DFS

## Activity Details
- Challenge: 17-B 09
- Activity ID: SY-S3-B-09
- Subject: Data Structures and Algorithms
- Programming Language: C

## Objective
To represent a file system as a graph using an adjacency matrix and search for a specified file using Breadth-First Search (BFS) and Depth-First Search (DFS).

## Concepts Used
1. Graph Representation
2. Adjacency Matrix
3. Breadth-First Search (BFS)
4. Depth-First Search (DFS)
5. Queue
6. Recursion

## Program Features
- Represents files and directories as graph nodes.
- Represents connections using an adjacency matrix.
- Performs BFS traversal.
- Performs DFS traversal.
- Searches for a specified file.
- Displays whether the file is found or not.

## How to Compile and Run

Compile:
gcc filesystem.c -o filesystem.exe

Run:
./filesystem.exe

## Conclusion
This project demonstrates the application of graph representation and searching algorithms in a file system. Both BFS and DFS are implemented to traverse the graph and search for files.
